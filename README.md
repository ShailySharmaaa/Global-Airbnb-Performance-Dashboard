# Global-Airbnb-Performance-Dashboard
🏠 Airbnb Analytics: Global Airbnb Performance Dashboard
## Project Title / Headline
   
Airbnb Analytics: Global Airbnb Performance Dashboard
An interactive data visualization dashboard designed to analyze Airbnb listings, host performance, review behavior, and market distribution across major global cities. The dashboard highlights insights related to listing growth, pricing trends, customer engagement, and host trust indicators to support data-driven decision making in the short-term rental industry.

## Short Description / Purpose

The Airbnb Performance Dashboard is an interactive Power BI report built to analyze over 279,000 Airbnb listings across 10 major cities worldwide. The dashboard enables users to explore patterns in listing growth, pricing structures, host verification, customer reviews, and city-level market share.
This dashboard helps data analysts, tourism strategists, hospitality businesses, and investors understand trends in the global short-term rental market and identify high-performing locations and property types.

## Tech Stack
 
The dashboard was developed using the following tools and technologies:
• 📊 Power BI Desktop – Main platform used to build interactive dashboards and visualizations.
• 🔄 Power Query – Used for data cleaning, transformation, and preparation before loading the data into Power BI.
• 🧠 DAX (Data Analysis Expressions) – Used for calculated measures, KPIs, and dynamic data analysis.
• 🗂 Data Modeling – Relationships created between datasets such as listings, hosts, reviews, and cities to enable filtering and cross-analysis.
• 📁 File Formats
.pbix – Power BI development file
.png – Dashboard preview images for documentation and presentation

## Data Source

The dataset used in this project was obtained from Maven Analytics, which provides real-world datasets for analytics learning and portfolio projects.
The dataset represents listing and host information from Airbnb, covering multiple cities around the world.
Dataset includes information such as:
• Listing details (property type, room type, and pricing)
• Host details (identity verification and profile picture availability)
• Review information (review counts and review frequency)
• City-level listing distribution
• Customer ratings across multiple categories such as accuracy, cleanliness, communication, location, and value

Dataset Overview

• 279,712 Listings
• 182,024 Hosts
• 144 Property Types
• 5,373,143 Reviews
• 10 Global Cities
This dataset enables analysis of Airbnb market distribution, pricing trends, customer satisfaction, and host trust indicators across different cities.

## Features / Highlights
Business Problem

The growth of short-term rental platforms like Airbnb has significantly changed the hospitality industry. However, analyzing large datasets containing thousands of listings, hosts, and reviews makes it difficult to quickly understand market trends, city performance, and customer satisfaction levels.

Key questions that stakeholders often struggle to answer include:

• Which cities dominate the Airbnb marketplace?
• How have Airbnb listings grown over time?
• Which property types are most common and most expensive?
• How trustworthy are hosts based on verification indicators?
• How do customer reviews and ratings vary across cities?

Without proper visualization tools, extracting these insights from raw data can be time-consuming.

Goal of the Dashboard

The main objective of this dashboard is to create an interactive analytical tool that enables users to:

• Explore Airbnb listing growth over time
• Compare market share across global cities
• Analyze pricing differences between property types
• Understand customer review patterns and engagement levels
• Evaluate host trust indicators and verification status
• Compare city-level ratings and seasonal tourism trends

The dashboard provides a clear, visual overview of Airbnb's marketplace performance and customer behavior.

## Walkthrough of Key Visuals
1️⃣ Global Listings Overview (KPI Cards)

The dashboard begins with key performance indicators summarizing the dataset:

• 279,712 Total Listings
• 10 Cities Covered
• 182,024 Hosts
• 144 Property Types

These metrics provide a quick overview of the size and activity of the Airbnb ecosystem.

2️⃣ Listing Growth Over Time (Line Chart)

A line chart shows how Airbnb listings evolved between 2008 and 2020 across different property types:

• Entire Place
• Private Room
• Shared Room
• Hotel Room

Key Insights

• Airbnb experienced rapid expansion between 2012 and 2016.
• Entire place listings dominate the market, showing strong demand for full property rentals.
• Listings decline slightly in 2020 due to the impact of the COVID-19 Pandemic on global travel.

3️⃣ Market Share by City (Bar Chart with Cumulative Percentage)

This chart compares Airbnb listings across major cities including:

• Paris
• New York City
• Sydney
• Rome
• Mexico City
• Istanbul
• Rio de Janeiro
• Bangkok
• Cape Town
• Hong Kong

Key Insights

• Paris has the largest number of listings and reviews.
• Paris, New York, and Sydney together contribute a significant share of total listings, highlighting their importance as global tourism destinations.

4️⃣ Property Pricing Comparison

This chart compares average prices across property types:

• Hotel Room – Highest price
• Entire Place – Premium pricing
• Private Room – Moderate pricing
• Shared Room – Most affordable option

Insight

Hotels remain the most expensive accommodation option, while shared rooms serve budget travelers.

5️⃣ Review Frequency Analysis

This visualization analyzes how frequently guests leave reviews.

Key Findings

• Most users leave between 1 and 3 reviews.
• A small number of users leave extremely high review counts, indicating very active travelers or possible data outliers.

This helps identify customer engagement patterns on the platform.

6️⃣ Host Trust & Verification

A trust indicator evaluates hosts based on:

• Identity verification
• Profile picture availability

Insights

• More than two-thirds of hosts are fully verified.
• Very few hosts lack both verification and profile pictures.

This suggests strong trust and safety measures within the Airbnb platform.

Each city is evaluated on:

• Communication

• Value

Cities compared include:

• Paris
• New York City
• Sydney

Insights

8️⃣ Monthly Review Share by City (Ribbon Chart)

Cities analyzed include:

• Paris

## Key Insights

• Paris and Rome dominate review share between April and August, reflecting peak European travel seasons.
• New York sees increased review activity in November and December, aligning with holiday tourism.
• The ribbon chart highlights seasonal tourism demand shifts across different cities.
